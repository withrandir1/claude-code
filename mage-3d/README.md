# Маг Withrandir — движок персонажа со сменными скинами

Прототип на Three.js. Та же схема, что у мобильных игр с живым персонажем (Talking Tom, Om Nom):
скелет + скины + машина действий + реакции на касание + своя жизнь в покое.

## Слои

| Файл | Что делает |
|---|---|
| `js/engine.js` | Сцена: рендер, свет витрины, подиум, свечение, мягкий контур по краю (rim) для материалов |
| `js/geometry.js` | Мягкие формы: тела вращения со складками ткани, трубки с сужением, звёзды, орнамент |
| `js/rig.js` | Скелет: точки крепления `body, chest, head, hat, armL/R, handL/R, grip, footL/R`. Лицо и руки |
| `js/skins.js` | Скины по слотам: `hat` (обязательный), `staff`, `boots`, `robe`, `beard` |
| `js/wardrobe.js` | Надеть/снять скин, набор (loadout) как данные |
| `js/motion.js` | Кривые, треки действий, приоритеты, шаг, пружинящие звенья |
| `js/fx.js` | Кольца света, искры, пыль |
| `js/input.js` | Вращение пальцем, тап по зонам тела |
| `js/main.js` | Сборка и кадр |

## Правило, на котором всё держится

Анимации двигают **только скелет**. Скины **только крепятся** к скелету.
Поэтому любая новая шляпа или посох сразу работает со всеми действиями.

## Как добавить скин

```js
// js/skins.js
function hatWitch(r) {
  const m = cloth(0xdce5f0);
  mesh(lathe([/* профиль полей */]), m, r.hat);
  const links = tipChain(r.hat, m, [/* звенья кончика */]);
  return { chains: [{ links, gain: 1.3 }] };   // кончик пружинит сам
}
SLOTS.hat.skins.witch = { name: 'Ведьмина', build: hatWitch };
```

Что может вернуть `build(rig)`:
- `chains` — звенья, которые отстают от тела по инерции (кончик шляпы, пряди, концы шарфа, хвосты пояса);
- `focus` — точка магии: из неё идут свечение, кольца, искры;
- `glowMat` — материал, который светится цветом состояния;
- `update(t, dt)` — собственная жизнь скина (вращение звезды, орбиты искр в сфере).

## Поведение

- **Реакции на касание:** шляпа → приплющилась и спружинила; голова → оглянулся; мантия, ноги → party; посох → колдует.
- **Действия:** `party`, `cast`, шаг «странствует».
- **Жизнь в покое** каждые 6–10 с: оглядывается, потягивается, стучит посохом.
- **Приоритеты:** реакция прерывает фоновую возню, переход сглаживается за 200 мс.

## Перенос в iOS

| Здесь | iOS (RealityKit) |
|---|---|
| `rig` — группы с точками крепления | иерархия `Entity`, у каждого слота свой anchor |
| скин = `build(rig)` | скин = файл `.usdz` / `.glb` с тем же набором точек |
| `ACTIONS` — треки ключей | те же треки в Swift или `AnimationResource` |
| `Chains` | тот же расчёт пружин в `System` на кадр |
| `loadout` JSON | профиль пользователя в Supabase |

Продакшен-скины лучше моделировать в Blender с теми же точками крепления.
Код скелета, анимаций и гардероба при этом не меняется.

## Сборка

Страница грузит один файл `js/mage.bundle.js`: исходники из `js/` вместе с Three.js r170, без внешних загрузок.
После правки исходников пересобрать:

```bash
npm i three@0.170.0 esbuild@0.24.0
npx esbuild mage-3d/js/entry.js --bundle --minify --format=iife --target=es2020 --outfile=mage-3d/js/mage.bundle.js
```
