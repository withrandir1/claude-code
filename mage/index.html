Живой прототип героя, собранный так же, как анимируются персонажи Duolingo: персонаж разбит на слои, а поведением управляет state machine с входами. Нажми на мага, дай ему заклинание или напиши фразу, и он её произнесёт.

Каждая буква превращается в форму рта (визему). В приложении то же самое делается по аудио.

Как этот маг попадёт в iOS

Duolingo анимирует своих персонажей в Rive: векторный персонаж с костями, а все эмоции и переходы живут в state machine внутри одного файла .riv. Код приложения только дёргает входы. Этот прототип построен по той же схеме, поэтому переносится один к одному.

  1. Персонаж по слоямГолова, глаза, зрачки, брови, рот, борода, шляпа, кончик шляпы, руки, посох, сфера. Эти SVG-слои импортируются в Rive как есть.
  2. Риг и state machine в RiveКости на руки и шляпу, анимации idle, blink, happy, sad, cast, визем рта. Переходы по входам из таблицы ниже.
  3. Подключение в SwiftUIRiveRuntime через Swift Package Manager. Файл весит десятки килобайт и рендерится в 60 fps.
ВходТипЧто делает

import SwiftUI
import RiveRuntime

struct MageView: View {
    @StateObject var mage = RiveViewModel(fileName: "mage", stateMachineName: "Main")

    var body: some View {
        mage.view()
            .onTapGesture { mage.triggerInput("surprise") }
    }

    // правильный ответ в уроке
    func onCorrect()          { mage.triggerInput("happy") }
    func setMood(_ m: Double)  { mage.setInput("mood", value: m) }
    func setViseme(_ v: Double){ mage.setInput("viseme", value: v) }
}
