# aura-lab

Локальный конфигуратор-симуляция семантики Withrandir. Один файл `index.html`: без сборки, без внешних зависимостей (canvas + чистый JS). Приложение не затрагивает.

## Как открыть

Двойной клик по `tools/aura-lab/index.html` (или перетащить в браузер). Сервер не нужен.

- Слева — ручной ввод: цифра 0–9, intensity, валентность, tag, parents, «добавить событие», undo, reset, автосим, экспорт/импорт JSON.
- В центре — аура (тень тессеракта) и строка статуса: level, order, открытых цепей, циклов, узлов, spiralTurns, валентность, масштаб, колец.
- Справа — граф тегов (силовая раскладка) и лог событий, новые сверху.

Клавиши: `0`–`9` — сразу добавить событие с этой цифрой, `Enter` — добавить выбранную, `V` — сменить валентность.

Палитра временная (в репозитории палитры приложения нет): все hex-коды в объекте `PALETTE` в начале скрипта — заменить там.

## Цифры

| Цифра | Цвет | Смысл | Что делает в симуляции |
|---|---|---|---|
| 0 | белый | замкнутый цикл, целостность | если есть открытая цепь длины ≥ 3, замыкает самую длинную ребром последний → первый; последний узел становится белым |
| 1 | синий | один луч, один узел | узел + хеббовское ребро от parent |
| 2 | зелёный | последовательный рост цепи | то же |
| 3 | жёлтый | открытая цепь из 3, может замкнуться (→ 0) | то же |
| 4 | оранжевый | тетраэдр, все связаны со всеми, первый объём | то же |
| 5 | красный | замкнутая структура + лишняя связь, фокус | то же |
| 6 | розовый | выход в новое измерение (6 узлов, полная связность) | то же |
| 7 | фиолетовый | обратный ход по циклу, от цели назад | reverse += intensity на входящем пути; разворачивает направление вращения XW |
| 8 | create | переход на порядок выше, два цикла, перенос разряда | если в графе есть цикл: level += 1, аура ×φ, все веса ÷φ, новое кольцо. Без цикла не срабатывает (показывается в статусе и в логе ✗) |
| 9 | withrandir | зеркало 6, новый виток спирали | как 6, плюс spiralTurns += 1, radius ×φ, новое кольцо, шаг 90° в плоскости ZW |
| 10 | = 0 | новый цикл | — |

Валентность стоит над цветами: страх −1, любовь +1. φ = 1.6180339887.

## Модель

**Лог**: `{t, digit, intensity, valence, tag, parents}`; `t` — номер шага и id события, `parents` — массив `t`. Лог append-only, undo снимает только последнее событие (состояние пересчитывается повтором лога). Авто-тег и авто-parent фиксируются в событии, поэтому экспортированный лог при импорте воспроизводит то же состояние.

- Авто-тег: если tag пуст и включён «авто-тег», события 1–6 и 9 получают тег вида `синий-1`. События 0, 7, 8 без явного тега узлов не создают.
- parents «авто» = последнее событие с тегом.

**Шаг `step(event)`**, по порядку:
1. Затухание: все энергии вершин, энергии узлов и оба веса рёбер × 0.97.
2. Энергия вершины тессеракта (цвет = `digit & 7`, валентность) += intensity. Смена валентности относительно прошлого события → шаг 90° в XW.
3. Узел тега: цвет = цифра события, энергия += intensity.
4. Хеббовское правило: для каждого parent ребро `parent.tag → tag` получает forward += intensity. Если уже есть обратное ребро, прибавка идёт в его reverse.
5. Правила цифр 0, 7, 8, 9 (таблица выше). Путь для 7: от тега события (или тега parent) назад по самым сильным входящим рёбрам.
6. Рёбра с forward + reverse < 0.05 удаляются.

**Структура графа** (направление рёбер a → b):
- циклы — число элементарных направленных циклов;
- открытые цепи — слабосвязные компоненты без цикла из ≥ 2 узлов;
- order = 0, если есть цикл, иначе min(число узлов в самой длинной цепи, 7).

## Аура

- Тессеракт: 16 вершин = 8 цветов × 2 валентности. Вершина (b2,b1,b0,v): x = b0, y = b1, z = b2 (двоичная запись цифры 0–7), w = v. Страх — внутренний куб (пустые кольца), любовь — внешний (сплошные точки).
- Проекция 4D → 3D перспективой по w, затем 3D → 2D перспективой по z.
- Вращения: XW — скорость от суммы intensity за последние 10 шагов, направление меняет 7, смена валентности даёт шаг 90° с анимацией; YZ — медленно и постоянно; ZW — шаг 90° на каждое 9.
- Свечение вершины = накопленная энергия её цвета и валентности. Рёбра — тонкие линии смешанного цвета двух концов.
- Фон: кольца радиусов r0·φ^k и золотая спираль. Кольца появляются только от 9 и от успешного переноса через 8.
- Покой (нет событий 5 с): углы стягиваются к симметричным, камера — к виду вдоль главной диагонали куба (тень — шестиугольник).
- Аура растёт в φ раз на каждый перенос; когда перестаёт помещаться в 600×600, включается авто-зум (показан в углу).
